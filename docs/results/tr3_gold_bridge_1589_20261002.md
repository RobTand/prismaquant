# TR3 Producer Gold-Record Bridge

This source change adds an optional producer-authored gold record to the
existing TR3 scorer and a corresponding existing `fill-control` caller case.
It does not upgrade any retained TR3 output or establish new GPU, TP2,
runtime-cell, numerical, energy, compiled or served-latency qualification.

The new record is published only after a full measured panel and the existing
candidate-cache, teacher/panel/source and native engine fences. Its no-spec
state comes from the actual entry/exit guard, never from an absent manifest
field. The canonical shipcard model identity is checked before/after and bound
into the runtime context beside the existing authenticated checkpoint-content
identity. The actual self-manifest must observe a live engine descendant.
The record retains method, calibration, teacher, source and runtime evidence
and is consumed through the existing offline receipt ingestor. No canonical
manifest file or artifact bytes are fabricated.

Root separately approved strengthening the existing optional uniform-control
comparison for fidelity, calibration digest and teacher evidence. Missing or
different control fields refuse; strict-JSON equality preserves type and
finite-value distinctions. Legacy flat candidates keep the original comparison.
An overclaiming docstring that called every gold record exact full-vocabulary
was corrected: all-position top-K gold remains a distinct instrument, while
this TR3 producer actually sums every vocabulary column in FP64.
