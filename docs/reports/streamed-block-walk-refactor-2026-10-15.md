# Ordinary streamed block ownership

Provenance: 2026-10-14 PrismaQuant architecture refactor, base `138069b7993`.

`StreamingContext.walk_layers` now owns the ordinary whole-forward opening prefetch, layer install, successor request and installed block release. It uses the existing delivery Future, LayerCache, resolver and unload machinery. `InstalledBlock` contains coordinates, source-delivery status and a release obligation, with no tensors or second cache. Close is idempotent. The context-managed iterator closes its current block on break or work failure. A runner-pinned block is borrowed and remains installed until its pin owner releases it.

Three existing production compositions move to this owner: `StreamedCausalLM.capture_boundaries`, `StreamedCausalLM.__call__` and the expert format-fork forward. Each uses an explicit block scope, so unloading still precedes progress and memory observations. Scientific work, activation capture order, shared pass state and fork creation/advancement stay in the caller. Their normalized work ASTs match the pre-unit source in `s2-scientific-work-source-invariant.json`. Opening and successor numeric targets, required-prefetch flags and default install top-up remain unchanged. All three callers of this bounded policy migrated, with no fallback or compatibility alias.

A callback walk was rejected because it would put hidden-state/fork mutation in closures and require another callback for post-unload progress. The chosen iterator keeps both scientific work and the release boundary visible. The migration recipe `migrate_s2_forward_walks.py` is rerunnable against the documented pre-unit checkout. Logical CPU fixtures expose the actual owner API; new tests exercise real safetensors, delivery Futures, cache settlement and install/unload rather than a no-op loader.

The first unit deliberately retains distinct policies. Selected snapshots use sparse ordering, snapshot-only installation, completed-layer/page release and a byte-bound copy. Layer-major capture owns exact/bounded/recovery geometry, reassert/retry and settlement inside sealed source phases. AURA, Joint Stage A/quantum and Tessera retain their source/capture phases, successor settlement and chain windows. MTP and selected-layer measurement retain their scoped source and trim accounting. Native export uses authenticated shard/resolver batch installation and is owned by the export worker. Ordinary probe forwards and reverse sweeps with source-wall/gradient/trim observations remain a following unit; this commit does not claim that all traversal policies are one algorithm. Details and caller inventory are in `s2-block-walk-design.md` and `s2-traversal-callers.txt`.

The immediate PB baseline passes 82 cases over six files, no skips. The final 13-file cohort passes 160 cases, no skips, with complete collection, outcomes and teardown. All seven changed Python files compile. Existing streamed/resident numerical, expert reduction, source-page, retained-window, initialization/forward fidelity and safety checks remain. No test was removed in this unit; duplication and seal baselines do not grow.
