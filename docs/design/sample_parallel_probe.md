# Retired sample-parallel probe

Execution and the five manual commands prepare-calibration,
prepare-worker-source-cache, merge-importance, build-cover and merge are archived
at [the retirement record](../../archive/sample_parallel_probe_2026-10-15/README.md).
The complete former runbook is in that archive. The incremental CLI still refuses
`--global-calibration-tensor` before reading any checkpoint.

Recorded shard and precompute reuse retain their source-census, token/shape,
digest, dense-marginal and exact activation-priority checks in
`prismaquant.sample_parallel_artifacts`. Existing merged activation reads retain
their independent byte and stamp checks in `ActivationIndex`. Archived execution
cannot authorize a current worker. Restoration requires a lane-independent source
census and a separately reviewed execution contract.

Provenance: 2026-10-14 PrismaQuant architecture refactor, base 138069b7993.
